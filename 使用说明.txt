============================================================
ClassIn 自动登录 — 使用说明（Windows）
============================================================

本工具作用：双击后自动启动 ClassIn 并填入你的账号密码、按回车登录。
零额外依赖，只用系统自带的 PowerShell。

------------------------------------------------------------
一、首次配置（只需做一次）
------------------------------------------------------------
1. 把整个 classin-auto-login 文件夹拷到 Windows 机器上
   建议放非云同步目录，例如 D:\Tools\classin-auto-login\
   （若从 GitHub 克隆，请先复制 classin_credentials.txt.example 为 classin_credentials.txt）

2. 用记事本打开 classin_credentials.txt，把两行示例值改成
   你自己的账号和密码，保存。

3. 双击「运行ClassIn自动登录.bat」试一次。

------------------------------------------------------------
二、如果账号密码没填进去（常见：焦点问题）
------------------------------------------------------------
ClassIn 是自研客户端，键盘模拟不一定能准确落到输入框。
此时改用“坐标模式”，100% 可靠：

1. 先手动打开 ClassIn 登录窗口，放在不被遮挡的位置。
2. 双击「获取坐标.bat」。
3. 按提示把鼠标移到【账号输入框】，按 Enter；
   再移到【密码输入框】，按 Enter。
   坐标会自动写进 classin_config.txt。
4. 之后每次双击「运行ClassIn自动登录.bat」即用坐标模式登录。

------------------------------------------------------------
三、ClassIn 路径不对怎么办
------------------------------------------------------------
若双击后提示“找不到 ClassIn”，说明 classin_path 不对。
打开 classin_config.txt，把 classin_path 改成你机器上
ClassIn.exe 的真实路径（可在开始菜单右键“打开文件位置”查看）。

------------------------------------------------------------
四、安全提醒（重要）
------------------------------------------------------------
- classin_credentials.txt 是【明文密码】，仅限个人本机使用。
- 切勿放入 OneDrive / 百度网盘等任何云同步或共享目录。
- 建议收紧文件权限（在文件夹里 Shift+右键“在此处打开 PowerShell”，执行）：
    icacls "classin_credentials.txt" /inheritance:r /grant:r "%USERNAME%:R"
- 更安全的做法是用 Windows 凭据管理器，但需要改写脚本，
  如需我可再给你一版。

------------------------------------------------------------
五、其他提示
------------------------------------------------------------
- 首次运行若弹出“更新 / 用户协议”窗口，请先手动处理一次，
  之后再双击脚本即可。
- 若你曾勾选“记住密码 / 自动登录”，客户端可能直接进主页，
  此时本脚本无需运行。
- 如仍失败，请把黑色窗口里的报错文字发我，我据此微调。
